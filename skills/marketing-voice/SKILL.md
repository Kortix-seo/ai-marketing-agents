# Marketing voice for an open-source Kortix project

Kortix is open source. This file is the register every marketing draft is written in: a session that writes marketing copy reads it before the first sentence, and every draft is measured against it. The agent does not carry a house style in its head: it reads this, and here is where a change lands.

## The one-edit rule

A correction to the register is one edit to this file. Every later draft inherits it, and no draft gets a private exception.

If a draft needs a sentence this file forbids, the draft is wrong. Broken register rules are fixed here, in a change request of their own, so the reviewer can see the rule they are agreeing to. A correction buried inside an asset edit is invisible to the next session and gets repeated.

## Register rules

1. Answer in the first sentence. The reader came for the thing, so give it before the context.
2. One idea per sentence, and one audience per sentence.
3. Active voice, present tense, second person for the reader.
4. Sentence length varies. A four-word sentence after a long one is fine, and a page of even-length sentences is not.
5. Name the mechanism, the number or the noun. Delete the adjective and check the sentence still stands.
6. No dashes as pauses. Use a period.
7. US spelling: center, color, organization, catalog.
8. Write product and company names the way their owner writes them, and check the owner's page when unsure.
9. A date is written `2026-10-26` in a claim record and spelled out in prose only when the reader needs it.
10. Say a fact once. Repetition across sections reads as padding, and a reader skips it.

## Banned words

These fail review on sight. Replace each with what the thing does.

- `leverage`, `seamless`, `robust`, `cutting-edge`, `next-gen`, `world-class`
- `revolutionary`, `game-changing`, `transformative`, `supercharge`, `unlock`, `empower`, `elevate`
- `solution` as a name for the product, `delve`, `holistic`, `synergy`
- `in today's fast-paced`, `it is not just X, it is Y`, `imagine if`

Any phrase claiming the work ships without a person is banned too. Work reaches `main` through a change request a person approves.

A superlative is allowed in one case: a measured comparison, in the same paragraph, with the measurement named and dated. Nothing else earns one.
